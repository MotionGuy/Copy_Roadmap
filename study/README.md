# study

Study guides shown in the roadmap's Study tab.

- Each guide is one self-contained HTML file: `study/<class>-<exam>.html` (for example `ics46-midterm.html`).
- A printable cheat sheet, if there is one, sits beside it as `study/<class>-<exam>-cheatsheet.html`.
- Every guide has an entry in the `study` list of the site's content (the database, or `content/content.js` when there is none). The tab lists what is in that array.
